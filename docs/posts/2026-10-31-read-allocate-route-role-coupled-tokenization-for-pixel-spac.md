## TL;DR
SpecSlot decouples output detail from global attention sequence length by expanding spatial anchors into spectrally-defined slots. This is achieved via an indexed W$\times$K representation and a carrier-routed GGLL attention mechanism, allowing for finer spectral resolution ($K$) without inflating the global communication cost, which remains tied to the anchor density ($W$).

## The Problem
Pixel-space generative Transformers, which operate by mapping one token to each image patch, inherently suffer from a computational bottleneck. Specifically, the quadratic complexity associated with dense attention scales directly with the total number of tokens. Since the patch grid dictates the token count, increasing the desired image detail—which necessitates a finer patch grid—directly inflates the quadratic term of the global attention mechanism.

## Key Contributions
We introduce three primary contributions to address this scaling issue:
1. An indexed W$\times$K representation that separates spatial anchor density ($W$) from spectral coefficient subdivision ($K$), allowing these two allocation variables to be tuned independently.
2. The definition of carrier-routed global$\to$global$\to$local$\to$local (GGLL) attention, which restricts global communication such that only the lowest-radial carrier per anchor participates in the global stage, thereby fixing the global sequence size to $W$ carriers rather than $WK$ slots.
3. Empirical demonstration that SpecSlot enables the selection of two distinct quality-compute operating points between the low-cost and high-cost regimes of JiT, achieving superior performance at lower computational budgets.

## How It Works

SpecSlot reframes the generation process around tokenization as an allocation problem, structured around three sequential operations: Read, Allocate, and Route.

The **Read** phase collects initial input evidence onto a grid defined by $W$ spatial anchors, which sample non-overlapping $s \times s$ cells of the input latent $z_t$. These anchors are then expanded into $K$ indexed slots. The **Allocate** phase assigns a fixed output role to each slot by partitioning the Discrete Cosine Transform (DCT) coefficients into $K$ disjoint radial groups. Crucially, the slot corresponding to the lowest frequency group (slot 0) is designated as the global carrier. Finally, the **Route** phase governs communication: only the slot 0 carrier from each anchor is permitted to enter the global attention stage, while all $K$ slots interact locally within their respective anchor neighborhood, resulting in the GGLL attention schedule. This mechanism successfully separates the fine-grained spectral representation (governed by $K$) from the global sequence length (governed by $W$).

### Spatial Anchors (W)
The Spatial Anchors define the coarse spatial sampling grid. They are the fundamental grid structure responsible for reading the initial input evidence from non-overlapping $s \times s$ cells of the latent representation $z_t$. The density of these anchors, $W$, dictates the size of the global communication sequence.

### Indexed Slots (K)
Each spatial anchor is expanded into $K$ distinct slots. The indexing is tied to the spectral domain; each slot is assigned a unique, disjoint radial group of the DCT coefficients derived from the anchor's input evidence. This allows the model to represent finer spectral detail by increasing $K$ without increasing the anchor count $W$.

### Input Mixer
Prior to slot expansion, an Input Mixer operates over the anchor grid. This component is implemented as a zero-initialized residual depthwise $3 \times 3$ convolution. Its function is to facilitate local information exchange, allowing evidence from neighboring spatial anchor cells to be aggregated before the spectral slot expansion occurs.

### Global Carrier (Slot 0)
The Global Carrier is a specific designation within the Indexed Slots. For every spatial anchor, the slot assigned the lowest-frequency DCT coefficient group is designated as the Global Carrier. This carrier is the sole representative of that anchor permitted to participate in the global attention mechanism.

### GGLL Attention
The GGLL Attention defines the communication topology. It is a carrier-routed schedule structured as two consecutive global blocks followed by two local blocks, repeated three times. This structure ensures that global information flow is constrained only to the $W$ carriers, while local refinement occurs across all $K$ slots within their anchor context.

### Spatial Head
The Spatial Head provides a mechanism for local refinement post-spectral prediction. It is a secondary attention head that reads out the state of the $K$ slots directly in pixel space. Its output is used to provide an anchor-aligned local correction term to the primary spectral prediction.

## Why This Matters
The core implication of SpecSlot is the decoupling of representational capacity from communication overhead. By separating the spectral resolution ($K$) from the spatial sampling density ($W$), we gain the ability to independently tune the model's fidelity against its computational budget. The restriction of global attention to only the lowest-frequency carrier per anchor effectively reduces the quadratic complexity from $O((WK+C)^2)$ to $O((W+C)^2 + WK^2)$. Furthermore, the dual-basis output structure—a spectral base ($r_{spec}$) and an anchor-aligned spatial correction ($r_{sp}$), summed in pixel space—provides a robust mechanism for integrating global context with localized detail.

## Limitations & Open Questions
One noted limitation is that the two output terms, $r_{spec}$ and $r_{sp}$, technically express the same underlying prediction but in different bases. The authors suggest that Section 6.1 demonstrates their content is complementary rather than redundant. Additionally, the provided complexity analysis is simplified, as it deliberately ignores the computational cost associated with projection layers and elementwise operations.
