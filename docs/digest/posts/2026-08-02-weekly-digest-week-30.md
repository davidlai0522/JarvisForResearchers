## Papers This Week

### [AXIS: A Growable Community-Driven Data Engine for Scalable Robot Manipulation](https://arxiv.org/abs/2607.21588)
*AXIS is a growable, community-driven data engine and benchmark that enables scalable robot manipulation learning by unifying task generation, browser-based teleoperation, data refinement, realistic augmentation, and policy learning with real-world validation.*
The system builds a dataset of 207 tasks and 50K+ trajectories, utilizing a pipeline that includes IsaacSim-based visual and physics augmentation. Continual pretraining on AXIS-100% resulted in a 5.8% improvement in the Overall LIBERO-Plus success rate compared to the baseline $\pi0.5$.

**Why it matters:** For scalable robot learning, move beyond static datasets by implementing continuous data generation and collection pipelines.

### [SM4RT: Learning Structured Motion Geometry for 4D Reconstruction](https://arxiv.org/abs/2607.22534)
*SM4RT introduces Structure-of-Motion (SoM) to represent 4D scene dynamics by decomposing motion into a compact set of motion bases, allowing for end-to-end 3D reconstruction and structured motion perception from monocular RGB video in a single forward pass.*
The method decomposes motion into $N$ motion bases, each represented as a temporal sequence of 6D twists in $\text{se}(3)$. This approach replaces over-parameterized per-pixel displacement fields with a compact, physically grounded decomposition.

**Why it matters:** For dynamic scene understanding, shift from point-wise displacement estimation to modeling motion using rigid kinematic entities ($\text{SE}(3)$ twists) for physically consistent results.

### [Data Pyramid for Embodied Manipulation](https://arxiv.org/abs/2607.24744)
*This paper organizes the embodied data ecosystem into a five-layer 'Data Pyramid' based on the tension between scalability and robot alignment, characterizing data sources by quality, diversity, reusability, and physical fidelity.*
The pyramid characterizes data sources across five layers: real-robot, UMI-style, egocentric/exocentric, simulation, and general data. Analysis shows a transition from early training recipes dominated by real-robot trajectories toward increasingly heterogeneous mixtures of data types.

**Why it matters:** When designing data collection pipelines, consider the trade-off between high physical fidelity (e.g., Real-Robot Data) and high scalability (e.g., General Data).

### [Pass the Baton: Trajectory-Relayed On-Policy Distillation](https://arxiv.org/abs/2607.26057)
*Relay On-Policy Distillation (Relay-OPD) addresses prefix failure in On-Policy Distillation (OPD) by using a label-free handoff trigger to allow the teacher to briefly correct the student's trajectory before the student resumes generation.*
Relay-OPD utilizes a budgeted relay rollout, achieving a +5.73% outperformance over standard OPD across eight math reasoning benchmarks for the 1.7B student. This method also cuts the average training trajectory length by over 50%.

**Why it matters:** Early and local teacher intervention is highly effective for correcting prefix failure, requiring minimal teacher token usage (as low as 0.35%).

### [VidMap: Exploiting Temporal Structure for Video-Based Structure-from-Motion](https://arxiv.org/abs/2607.27194)
*VidMap combines the sequential constraints of SLAM with the global optimization of offline SfM, augmented with metric monocular depth priors and provenance-aware tracking, to achieve robust metric reconstruction of arbitrary, long, uncalibrated videos.*
The system integrates the strong sequential constraints of SLAM with the global optimization capabilities of offline SfM. It augments this process with metric monocular depth priors to mitigate scale drift and handle degenerate configurations.

**Why it matters:** For long, unconstrained video reconstruction, combining sequential tracking (SLAM-like) with global optimization (SfM-like) is necessary to overcome the limitations of either approach alone.

### [ReToken: One Token to Improve Vision-Language Models for Visual Retrieval](https://arxiv.org/abs/2607.28627)
*RETOKEN introduces a single learnable embedding trained as an explicit retrieval target to select a sparse set of query-relevant visual tokens from a pre-filled visual KV cache, improving performance in long visual context tasks for Vision-Language Models (VLMs).*
The paper finds that retrieval scores computed in the value space, rather than the conventional query-key space, provide a stronger signal. RETOKEN achieved a 13.4 points improvement on Visual Haystacks using Qwen3VL-8B.

**Why it matters:** For long-context VLMs, shifting retrieval focus from query-key attention scores to value-space similarity offers a significantly stronger signal.

### [Learning to Trace Seiberg Dualities](https://arxiv.org/abs/2607.28628)
*This paper uses machine learning, specifically Graph Neural Networks (GNNs) and pathfinding algorithms, to address the computationally challenging problem of determining if two supersymmetric quiver gauge theories are related by a sequence of Seiberg dualities.*
The research demonstrates that network architectures outperform deterministic algorithms for quivers of order 10. Supplementing the network with pathfinder algorithms like the Distance GNN (DGNN) improves the efficiency and accuracy of the search strategy.

**Why it matters:** Integrating learned heuristics (from DGNN/AGNN) with established search algorithms (A*search) significantly improves the efficiency and accuracy of tracing dualities.
