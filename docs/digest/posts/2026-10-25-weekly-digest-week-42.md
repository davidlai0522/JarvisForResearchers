## Papers This Week

### [Which Tokens to Merge? Diffusion Dynamics for Efficient Image Generation](https://arxiv.org/abs/2610.22370)
*Dynamics-aware Token Merging (DaTMe) is a training-free framework that grounds token merging in diffusion dynamics by constructing a dynamics-aware importance map combining temporal evolution and structural saliency derived from the Tweedie denoised estimate.*
DaTMe constructs a dynamics-aware importance map using the Tweedie denoised estimate to capture both temporal evolution and structural saliency for token merging. This approach maintains visual fidelity across the entire image when validated on DiT and MM-DiT.

**Why it matters:** Token merging in diffusion models should be guided by diffusion dynamics (temporal evolution and structural content) rather than solely by text relevance (CFG).

### [Behavioral Couplings: From Formation to Behavioral Emergence in Language Models](https://arxiv.org/abs/2610.23847)
*This work investigates behavioral couplings in LLMs, demonstrating that training on documents describing co-occurring behaviors can induce unintended, coupled behaviors that can even compose across different training sets.*
The study shows that training on co-occurring behaviors can create couplings, with expression rates ranging from 23% to 93% after Form+BFT. Furthermore, these couplings can compose, allowing a coupling to form between the first and third behavior when two document sets share a common behavior.

**Why it matters:** Evaluation of LLMs must go beyond a model’s current behavior to assess risks from later fine-tuning.

### [Text-to-Image Generative Modeling Without Language Pretraining](https://arxiv.org/abs/2610.26863)
*Halcyon, an early-fusion multimodal autoregressive model pretrained entirely from scratch on GPIC, demonstrates that strong text-to-image generation can be achieved without internet-scale language pretraining.*
Halcyon achieves a gFD of 48.0, which is competitive with LlamaGen-XL/8, while requiring 18.2$\times$ less total pretraining compute. The model also learns image captioning by replacing caption dropout with I2T supervision.

**Why it matters:** Early-fusion architectures, when trained end-to-end, can achieve competitive performance with significantly reduced pretraining compute compared to late-fusion baselines.

### [SolarRenderer: Few-Step Generative Reference Rendering](https://arxiv.org/abs/2610.28630)
*SolarRenderer is a structure-conditioned video renderer that adapts a frozen MiniMax-H3 33B backbone using lightweight LoRAs to render realistic video from arbitrary structural representations in few steps.*
The renderer handles any structural representation with a single control LoRA through the native reference pathway. This results in a rendering speed of four steps, which is 12.3 times faster than 50-step sampling.

**Why it matters:** Use native reference pathways instead of adding ControlNet branches to handle diverse structural inputs with a single adapter.

### [Think Harder Where It Matters: Item-Level Adaptive Recursion for Sequential Recommendation](https://arxiv.org/abs/2610.30128)
*LoopRec introduces item-level adaptive recursion for sequential recommendation by using a shared backbone and a lightweight gate at each recursion boundary to dynamically determine the necessary computation depth for each item.*
LoopRec achieves a +7.1% gain in NDCG@20 and a +6.5% gain in MRR@20 compared to fixed-depth processing. Routing analyses showed deeper computation was utilized for less frequent and more recent items.

**Why it matters:** Adaptive depth mechanisms, like LoopRec, can improve ranking quality while potentially reducing total computation.

### [A Unified Framework for Image-to-3D Part Generation via Variable Granularity](https://arxiv.org/abs/2610.31671)
*FlexPart is a unified framework that integrates sparse points, bounding boxes, and masks into a single Diffusion Transformer (DiT) using gated adaptive modulation and an Asymmetric Geometric Guidance mechanism for controllable image-to-3D part generation.*
FlexPart achieves a Part CD of 0.2938 when conditioned on masks, matching the performance of TripoSG + SAM3D and OmniPart. The framework allows users to select the required level of spatial control by choosing between sparse points, bounding boxes, or dense masks as input.

**Why it matters:** The framework benefits from joint multi-granularity training, allowing the model to leverage complementary information across different prompt modalities.

### [Cost-Aware Abstention for LLM-Based IT Ticket Classification](https://arxiv.org/abs/2610.31657)
*This paper evaluates cost-aware abstention policies for LLM-based IT ticket classification, demonstrating that selecting a routing threshold based on asymmetric costs can significantly reduce expected operational costs compared to standard routing.*
A calibration-selected, paired-bootstrap cost analysis showed a Test Cost Reduction of 0.472 compared to a baseline of 0.763. This translates to a relative cost reduction of 38.1% for the TF-IDF + LR baseline.

**Why it matters:** The choice of routing threshold ($\tau$) must be derived from an organization's specific cost structure, not solely from test tuning.

## Trends & Observations
* There is a clear trend toward efficiency in generative models, exemplified by Halcyon reducing pretraining compute by 18.2$\times$ and SolarRenderer achieving 12.3$\times$ speedup via few-step rendering.
* Control mechanisms are becoming more unified; FlexPart integrates multiple input modalities (points, boxes, masks) into a single DiT structure.
* In LLM safety and deployment, the focus is shifting from pure accuracy to operational cost and emergent risk, as seen in "Cost-Aware Abstention" and "Behavioral Couplings."
* Diffusion model efficiency research is moving beyond simple sampling speed to structural guidance, as demonstrated by DaTMe's use of diffusion dynamics for token merging.
* Sequential data processing is adopting adaptive computation, with LoopRec dynamically adjusting recursion depth based on item-level demand rather than using fixed-depth processing.
