## Overview
This week's research shows a clear trend toward enhancing model capabilities by integrating structured, domain-specific knowledge, whether that knowledge is geometric, perceptual, or procedural. Several papers address the limitations of standard LLMs in complex, real-world tasks; for instance, *Copy Less, Ground More* tackles repetitive copying in long-context reasoning using evidence-aware reward shaping. In the vision domain, there is a concerted effort to move beyond simple pixel-level representations, as seen in *ATSplat*'s compact 3D Gaussian Splatting and *VLM-IE3D*'s fusion of implicit and explicit geometry for 3D awareness. Furthermore, the evaluation landscape is maturing, with *UAV-DualCog* establishing a rigorous benchmark for embodied AI by demanding dual-cognition, while *The Many Senses of Visual Similarity* introduces TPIPS to capture nuanced, text-prompted perceptual similarity.

## Papers This Week

### [SciDiagramEdit: Learning to Edit Scientific Diagrams from Paper Revisions](https://arxiv.org/abs/2607.15272)
*SciDiagramEdit introduces a skill-evolution framework that learns to edit scientific diagrams from natural paper revisions by employing an agentic editor, a vision-language model judge, and a demonstration-aware coach.*
The framework builds SCIDIAGRAMEDIT, an editing benchmark of 364 before/after figure pairs, and trains a self-improving agent that distills execution traces into a portable skill specification. This agent achieves a best-so-far Success Rate (%) on the benchmark.

**Why it matters:** For instruction-driven editing, operating on the editable vector source is crucial for compositional control, unlike raster-level re-rendering.

### [Knowing the Self, Understanding the World: A Dual-Cognition Benchmark for UAV Spatio-temporal Reasoning with MLLMs](https://arxiv.org/abs/2607.16193)
*UAV-DualCog is a novel benchmark designed to jointly evaluate the dual-cognition capabilities—self-state and environment-state reasoning—of Multimodal Large Language Models (MLLMs) in aerial multiview spatio-temporal contexts.*
The benchmark systematically evaluates MLLMs, showing that proprietary models achieve 37.7% Rel. Position Acc and 14.2% Future Obs. mIoU@50. The benchmark also provides diagnostic validations to structure supervision for UAV-oriented MLLMs.

**Why it matters:** When evaluating MLLMs for embodied agents, ensure the evaluation explicitly tests both self-state awareness (agent's own state) and environment-state awareness (external scene state).

### [The Many Senses of Visual Similarity: A Text-Prompted Image Perceptual Metric](https://arxiv.org/abs/2607.18237)
*The Text-Prompted Image Perceptual Similarity (TPIPS) metric is introduced to capture context-dependent, multi-faceted visual similarity by fine-tuning a Vision-Language Model (VLM) on a large-scale dataset of human similarity judgments conditioned on free-form text prompts.*
The authors developed TPIPS by fine-tuning a VLM on a dataset of one million human similarity judgments across 25K image triplets. This metric narrows the performance gap considerably when compared to the strongest current VLM systems.

**Why it matters:** TPIPS allows for text-guided retrieval and compositional search by specifying the desired visual axis of similarity.

### [Copy Less, Ground More: Overcoming Repetitive Copying in Long-Context Reasoning via Evidence-Aware Reinforcement Learning](https://arxiv.org/abs/2607.19345)
*GEAR (Grounding Evidence-Aware Reward) is a reward shaping method that mitigates repetitive copying in long-context LLM reasoning by augmenting the accuracy signal with a grounding reward for key evidence overlap and a distractor penalty for irrelevant context overlap.*
GEAR combines a grounding reward ($\alpha \cdot \text{Overlap}_n(y|x_{\text{key}})$) and a distractor penalty ($\beta \cdot \text{Overlap}_n(y|x_{\text{dist}})$) to address repetitive copying. This method yields a +4.6 average points improvement over standard RL with accuracy-based rewards.

**Why it matters:** To improve grounding, consider reward shaping that explicitly differentiates between task-relevant evidence and irrelevant context, rather than relying solely on final accuracy.

### [ATSplat: Compact Feed-forward 3D Gaussian Splatting with Adaptive Token Expansion](https://arxiv.org/abs/2607.20417)
*ATSplat is a feed-forward 3D Gaussian Splatting framework that restores scene-adaptive capacity allocation by using sparse 3D anchor tokens and an Adaptive Token Expansion module to concentrate representational capacity in challenging regions.*
ATSplat achieves state-of-the-art rendering quality while using more than 5.7$\times$ fewer Gaussians than previous dense pixel-aligned methods. The reconstruction time is reported as less than a second from 12 input images at 512$\times$960 resolution.

**Why it matters:** To achieve compact, high-quality feed-forward 3DGS, decouple primitive placement from input image grids using sparse 3D anchor tokens.

### [3D-Aware VLMs with Implicit and Explicit Geometries](https://arxiv.org/abs/2607.21595)
*VLM-IE3D is a unified framework that enhances the 3D spatial awareness of Vision-Language Models (VLMs) by integrating both Implicit Geometry Tokens (IGTs) and Explicit Geometry Tokens (EGTs) derived from RGB videos, without requiring additional 3D inputs.*
The framework uses IGTs for high-level 3D priors and EGTs for detailed 3D structures, integrating them via a 3D-aware adapter. This approach results in a C@0.5$\uparrow$ of 80.4 on Scan2Cap, surpassing Qwen2.5-VL-3B [2].

**Why it matters:** To achieve fine-grained 3D understanding in RGB-only VLM pipelines, supplementing implicit scene priors with explicit, structured geometric tokens (EGTs) is highly effective.

### [Unified Video Dense Prediction from Disjoint Data](https://arxiv.org/abs/2607.21592)
*UniD is a unified video model that jointly predicts eight dense scene properties from disjoint, domain-specific datasets by leveraging the visual priors of a pretrained diffusion model and using lightweight task projectors to distill task embeddings.*
UniD uses a simple distillation step where per-task experts supervise a unified backbone via lightweight task projectors, eliminating the need for annotation overlap. It achieves superior Temporal Consistency compared to existing unified models.

**Why it matters:** UniD enables unified dense prediction across diverse tasks (geometry, semantics, intrinsics) without requiring co-annotated data.

## Trends & Observations
* There is a strong methodological shift toward augmenting standard model inputs with structured geometric or evidence-based tokens (e.g., EGTs in *VLM-IE3D*, evidence overlap in *Copy Less, Ground More*).
* Evaluation benchmarks are becoming more complex, moving beyond simple accuracy to test multi-faceted reasoning, such as dual-cognition in *UAV-DualCog* or aspect-conditioned similarity in *TPIPS*.
* Efficiency in 3D representation is a key focus, demonstrated by *ATSplat*'s ability to achieve high quality using significantly fewer Gaussians than dense methods.
* The concept of "skill evolution" or modularity is emerging, seen in *SciDiagramEdit*'s agentic learning and *UniD*'s modular task projectors.
* Researchers are actively finding ways to unify prediction across disparate data sources, as shown by *UniD*'s ability to handle disjoint datasets for dense prediction.
