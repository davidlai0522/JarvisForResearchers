## Papers This Week

### [Temporal Self-Distillation: Learning Visual State Tracking in Videos Without Supervision](https://arxiv.org/abs/2609.04203)
*S3T introduces a fully self-contained framework that uses temporal sampling density as privileged information to enable continuous visual state tracking in videos without relying on external labels or judges.*
The framework utilizes temporal sampling density as privileged information for self-distillation in Video-LLMs, allowing supervision from unlabeled videos. S3T improves cumulative-state reasoning while maintaining general video-understanding performance, achieving a VSTAT accuracy of 37.44 against a baseline of 34.74.

**Why it matters:** Self-distillation can be made fully self-contained by using temporal sampling density as privileged information, eliminating the need for external labels or judges.

### [WorldSculpt: Generating Compositional Worlds from Grounded Videos](https://arxiv.org/abs/2609.05416)
*WorldSculpt generates compositional 3D representations of densely cluttered scenes by adapting a single-object 3D generative prior (Pixal3D) with a multi-view conditioning pathway, allowing generalization to complex scenes without scene-level training.*
WorldSculpt maps multi-view scene observations into an anchor-aligned canonical frame, conditioning a strong object-level 3D generative prior on these aligned observations. This allows the generative prior, finetuned on individual objects, to generalize to large-scale scenes containing hundreds of objects without scene-level training.

**Why it matters:** Compositional 3D generation can be achieved by conditioning strong single-object priors on multi-view evidence, bypassing the need for scene-level training.

### [UniMate: One Unified Model to Animate Diverse Skeletons](https://arxiv.org/abs/2609.05415)
*UniMate is a unified foundation model that synthesizes articulated motion for arbitrary skeletons from a rigged 3D asset and a text prompt by employing a Topology-Aware Diffusion Transformer (TADiT).*
UniMate employs TADiT, which integrates motion and skeletal structure via a graph-aware attention bias and a global topological conditioner. This enables state-of-the-art performance on topology-agnostic motion generation and mesh animation across diverse skeletons.

**Why it matters:** UniMate enables zero-shot cross-topology transfer, in-betweening, expansion, and text-guided editing for 3D character animation.

### [TANGO: Humanoid Navigation in Cluttered Environments with a Whole-Body Vision-Language-Action Model](https://arxiv.org/abs/2609.09158)
*TANGO is a novel, whole-body vision-language-action (VLA) framework that enables language-conditioned humanoid traversal in cluttered indoor environments by directly predicting 29-DoF joint-space actions.*
TANGO directly predicts 29-DoF joint-space actions from language instructions and egocentric RGB observations, bypassing separate navigation and control modules. This resulted in a Success Rate (SR) of 70.31, compared to InternVLA-N1's performance.

**Why it matters:** For complex embodied tasks, moving beyond 2D waypoint planning to direct, high-dimensional joint-space action prediction is necessary for whole-body feasibility.

### [Precision in Rice Variety Classification using Stacking-Based Ensemble Learning](https://arxiv.org/abs/2609.10524)
*This research introduces a stacked ensemble learning framework, utilizing deep features extracted from a self-curated dataset of 20 rice varieties, to achieve 100% classification accuracy for rice variety identification.*
The authors developed a dataset of 20 rice varieties and extracted deep features using hyperparameter-optimized models. Applying a stacking-based ensemble approach to these baseline models resulted in a classification accuracy of 100%.

**Why it matters:** Stacked ensemble learning can significantly boost classification accuracy in complex image recognition tasks like rice variety identification.
