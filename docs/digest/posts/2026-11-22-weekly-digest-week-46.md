## Overview

## Papers This Week

### [BrickFlow: Connectivity-Guided Brick Reconstruction](https://arxiv.org/abs/2611.17321)
*BrickFlow learns an assembly prior using an SE(3) flow model trained on procedurally generated LEGO assemblies, which is then enhanced with analytic connectivity-field guidance at test time for improved structural validity.*
The method trains an SE(3) flow model on procedural data to learn an assembly prior, which is then augmented by an analytic energy term—the connectivity-field guidance—at inference. This guidance successfully increases the Valid (%) metric from 15.2 (IC DiT-L, no guidance) to 35.1 (with guidance) in Table 1.

**Why it matters:** For structure inference tasks with discrete constraints, combining generative priors (like flow models) with analytic guidance (like connectivity fields) is effective.

### [BAL: Bidirectional Autoregression in Latent Space for Learning Human Movement Representations](https://arxiv.org/abs/2611.18559)
*BAL introduces a self-supervised framework that learns human movement representations by exploiting the natural ordering structure of behavior through bidirectional autoregressive prediction in a latent space, while mitigating representation collapse via global and local component decomposition.*
BAL uses bidirectional autoregressive prediction to leverage temporal ordering constraints, decomposing the prediction target into a global component and a local component to suppress representation collapse. This approach yields a Captioning (CIDEr) score of 38.3, surpassing the baseline BehaveMAE [36] in Table 1.

**Why it matters:** Exploiting intrinsic data structure (like temporal ordering) provides a more principled supervisory signal than relying on heuristic augmentations or masking.

### [Latent Lattice Language Models](https://arxiv.org/abs/2611.21608)
*The Lattice of Latents (LLLM) increases language model computational capacity by introducing per-layer horizontal latent streams that run recurrently across time, complementing the standard vertical residual stream that flows through depth.*
LLLM introduces horizontal latent streams ($r_{\ell}^t$) that run recurrently across time and condition the vertical stream's attention, KV-cache writes, and MLP computation. The 406M-parameter LLLM achieves a Validation Perplexity of 14.40, which is lower than the baseline of 15.41 in Table 1.

**Why it matters:** Persistent per-layer state ($r_{\ell}^t$) offers a complementary axis for scaling LLM computation beyond depth or stream width.

### [Ambient LLMs: Data-Efficient Supervised Fine-tuning via Temperature Matching](https://arxiv.org/abs/2611.23229)
*Ambient SFT is a data-efficient fine-tuning framework that regularizes post-training by enforcing that the fine-tuned model matches the high-temperature conditional distributions of its pre-trained predecessor.*
Ambient SFT regularizes fine-tuning by matching the high-temperature conditional distributions of the pre-trained model, which is theoretically supported by the fact that conditionals contract as temperature increases. This technique resulted in up to 26.7% lower perplexity compared to the best baseline across five domain-adaptation targets in Table 1.

**Why it matters:** Ambient SFT allows for data-efficient post-training by leveraging the knowledge embedded in the pre-trained model via high-temperature sampling.

### [UltraTex: Aligning Physical Knowledge for High-Fidelity PBR Texture Generation](https://arxiv.org/abs/2611.24941)
*UltraTex is a cascaded multi-view framework that generates high-fidelity Physically Based Rendering (PBR) texture maps by integrating physical knowledge through material-semantic conditioning and photometric representation alignment into a diffusion-based pipeline.*
The framework uses a VLM-guided intrinsic material adapter to inject part-wise semantic priors into the MR generation process. It further guides intermediate MR diffusion features using photometric representation alignment, which controls material-light interactions.

**Why it matters:** For high-fidelity PBR generation, appearance matching alone is insufficient; explicit physical knowledge injection is necessary.

### [RL Post-Training in Diffusion Transformers Is Activation Steering](https://arxiv.org/abs/2611.26627)
*Fixed, input-independent steering vectors added to the block outputs of a frozen diffusion transformer base model can recover the majority of the reward gains achieved by full Reinforcement Learning (RL) post-training.*
The study found that fixed steering vectors, fitted without reward in the objective, recover 90.0–96.3% of the reward gain across six RL-tuned image models (Table 1). Specifically, matching the RL-tuned model's velocity predictions recovered more gain than using the simple mean-difference baseline.

**Why it matters:** For many RL-tuned diffusion models, the complex, input-dependent weight updates can be effectively approximated by a small set of constant activation shifts.

### [Posterior Matching Distillation](https://arxiv.org/abs/2611.26629)
*Posterior Matching Distillation (PMD) is a distribution-based distillation method that uses exponentially tilted means to supervise a stochastic student model, enabling it to recover the teacher's full conditional posterior while supporting any-step generation.*
PMD utilizes a conditional distribution-matching objective based on exponentially tilted means, which is made tractable via the Tilt=Shift Identity. This allows the student model to reproduce the target distribution without retraining, achieving the best FID among four-step methods.

**Why it matters:** PMD allows for efficient distillation by replacing expensive Monte Carlo sampling from the teacher posterior with a single evaluation at a shifted input.

## Trends & Observations
* There is a clear trend toward augmenting standard generative models with external, non-data-driven knowledge—whether it is analytic connectivity fields ("BrickFlow"), physical laws ("UltraTex"), or temporal structure ("BAL").
* Efficiency in post-training is a focus, with methods like "Ambient LLMs" and "RL Post-Training in Diffusion Transformers Is Activation Steering" demonstrating that complex fine-tuning can be approximated or regularized using simpler, fixed mechanisms.
* Architectural scaling in LLMs is being explored along new dimensions; "Latent Lattice Language Models" introduces a horizontal recurrent stream as a complementary scaling axis to traditional depth/width.
* Distillation techniques are evolving to target the full conditional posterior, as seen in "Posterior Matching Distillation," enabling more robust and diverse student models.
* The use of procedural data generation ("BrickFlow") is being validated as a method to create large-scale, constraint-rich training sets when real-world data is limited.
